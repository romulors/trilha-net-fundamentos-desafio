# Sistema de Estacionamento


DIO - Trilha .NET - Fundamentos - www.dio.me


## Desafio de projeto
Este desafio foi solucionado considerando o conteúdo da trilha .NET da DIO, baseado no repositório [trilha-net-fundamentos-desafio](https://github.com/digitalinnovationone/trilha-net-fundamentos-desafio).


## Contexto
Houve um contrata para construir um sistema para um estacionamento, que será usado para gerenciar os veículos estacionados e realizar suas operações, como por exemplo adicionar um veículo, remover um veículo (e exibir o valor cobrado durante o período) e listar os veículos. Também foi inserida uma funcionalidade de mostrar histórico dos eventos ocorridos.


## Proposta Implementada
Foi construída uma classe baseada na proposta inicial de "Estacionamento" focando na gestão do estacionamento. Outras responsabilidades (como a interface do usuário, as definições de veículos, placas e validações) foram distribuídas em outras classes.


## Utilização
Por último, foi feito um menu interativo com as seguintes ações implementadas:
1. Cadastrar veículo
2. Remover veículo
3. Listar veículos
4. Histórico
5. Encerrar
